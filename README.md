# MirrorKit Studio

本地优先的网页灵感与复刻素材库。粘贴网址，保存网页截图、页面结构和已加载资源，在统一界面浏览、预览、收藏，再把参考资料交给 Codex 进行复刻与改造。

## 功能

- 抓取当前页面，或最多 5 / 10 个同站页面。
- 网站卡片、截图和静态离线预览。
- 抓取队列、进度、停止和重试。
- 搜索、收藏、笔记、重命名、ZIP 导出。
- 保存当前选择，生成带本地资料路径的复刻任务。
- 数据留在本机，无需账号或云端存储。

## 安装与启动（macOS）

需要 Node.js 20 或更高版本，以及安装在标准位置的 Google Chrome。建议使用当前 Node.js LTS 版本。

```sh
git clone https://github.com/zhanyina1205-ai/mirrorkit-studio.git
cd mirrorkit-studio
npm ci
npm run app
```

安装完成后，也可以双击仓库中的 `launch.command`，在独立 Chrome 应用窗口中打开。该窗口依赖本地 Node.js 服务和 Chrome，不是包含运行时的独立安装包。

只启动后台服务：

```sh
npm start
```

访问 http://127.0.0.1:47831/ 。后台和预览只监听本机；预览端口为 47832。使用 `PORT` 自定义服务端口时，预览占用下一个端口；应用启动器固定使用默认端口。

## 从参考网站开始创作

1. 粘贴公开网站网址并等待抓取完成。
2. 选择卡片，查看截图和离线预览。
3. 点击「以此为参考，开始复刻」，填写改造要求并生成任务。
4. 复制任务到有本地文件访问能力的 Codex。若 Codex 已在本仓库工作，也可以直接让它读取 `data/selected.json`。

应用只准备参考资料，不会自动发送消息或调用付费模型。复刻结果应保存到新的目录，原始素材保持不变。

## 数据与备份

| 路径 | 内容 |
| --- | --- |
| `data/library.json` | 网站索引 |
| `data/sites/<id>/` | 截图、页面、资源、manifest 和复刻资料 |
| `data/selected.json` | 最近选择的网站及已生成的任务 |
| `data/trash/` | 从素材库移除后保留的文件 |
| `data/app-browser/` | 独立应用窗口的浏览器配置 |

整个 `data/` 目录均被 Git 忽略，不会随源码推送。备份时复制该目录。不要把浏览器配置、抓取内容或本地数据提交到仓库。关闭应用窗口后服务仍继续运行，避免中断抓取；重启电脑后重新打开即可。

## 抓取限制

使用独立且未登录的浏览器访问公开网页，不继承个人浏览器登录状态。保存 1440 × 1000 截图、渲染后的 HTML 和实际加载的资源。

离线预览禁用脚本、表单和外部请求，因此动画、登录、支付、流媒体和后端功能需要重新实现。快照可能与截图有差异，也不等同于目标网站的源码仓库。每次最多运行 3 分钟、保存 400 个资源或 120 MB；单个资源最大 20 MB。浏览器在读取响应期间仍可能产生额外网络和内存开销。

GitHub 用于保存源码。GitHub Pages 无法运行 Node.js 抓取后台，不能直接部署此完整应用。请使用本地运行方式，不要将管理 API 公开到互联网。

仅保存和使用有权访问、复制的内容，遵守目标网站的条款与相关许可。

## 开发

```sh
npm ci
npm test
node --check server.cjs
node --check capture.cjs
node --check public/app.js
```

核心文件：`server.cjs`（索引与 API）、`capture.cjs`（抓取与离线化）、`public/`（界面）、`bootstrap.cjs`（独立窗口启动）。测试覆盖地址限制；真实网站抓取效果需在本机安装 Chrome 后验证。
